1.Intel、AMD

原笔记图示：Intel 与 AMD 指令集关系

  • CPU 通过指令集工作。
  • Intel 的 8086、80186、80286 等处理器形成了 x86 指令集体系，通常称为 x86_32。
  • AMD 在此基础上扩展出 AMD x86_64，也就是常见的 x64 / AMD64。

2.ARM

原笔记图示：ARM 指令集特点

ARM 主要面向移动端和嵌入式设备，特点包括功耗低、发热少和集成度高。

大厂 Git 协作规范的可视化指南

635- 2m

一、 🌳 分支命名与用途

用固定前缀明确分支职责，做到“一眼识用途，合并零误解”。

  • master (生产主干) 👑：只存放最稳定、随时可上线的代码。

  • develop (开发主干) 🛠️：日常开发主线，承载所有新功能的迭代。

  • feature/* (功能分支) ✨：用于开发单一需求（例：feature/user_login），一需求一分支，互不干扰。

  • test/* (测试分支) 🐛：专供测试同学寻找和验证 Bug。

  • release/* (预发分支) 🚀：作为上线前的最后彩排与验证。

  • hotfix/* (急救分支) 🚑：线上 Bug 的紧急修复通道，修复完毕需同步合并回主干。
