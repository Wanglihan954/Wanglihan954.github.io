学习完成
2026-08-27 至 2026-09-09 完成面向 AI/CV 工程的 Modern C++ 第一轮学习。基础阶段测试为 29 / 30，最终综合测试为 35 / 35；这页按最终笔记内容重整，作为整套笔记的阅读入口。

这套笔记解决什么问题

目标不是穷尽 C++ 标准，而是建立一条能落到 AI/CV 工程的知识链：读懂对象如何保存数据、谁拥有资源、接口如何扩展，以及一个 CMake 工程怎样组织和构建。

完成后应能够：

  • 阅读 KuiperInfer、OpenCV、TensorRT 风格代码中的类型、所有权与数据流；
  • 判断参数传递、对象生命周期、Copy / Move 与智能指针的含义；
  • 用 Template、Polymorphism、RAII 组织一个小型推理网络；
  • 用 CMake 构建多文件 C++ 项目；
  • 遇到具体问题时回到对应主题查阅，而非重新从头刷课。
