详解所有分区类型

一、 磁盘分区表方案 (Partitioning Schemes)

这是磁盘最底层的管理标准，决定了磁盘能支持多大的容量以及能分多少个区。

1. MBR (Master Boot Record) - 主引导记录

  • 历史背景：1983 年随 DOS 2.0 推出，属于传统的“Legacy”标准。

  • 核心限制：

    • 容量限制：最高仅支持 2TB 的磁盘空间。超过 2TB 的部分将无法识别。

    • 分区数量：最多只能有 4 个主分区（或 3 个主分区 + 1 个扩展分区）。

    • 可靠性：分区信息只存储在磁盘的第一个扇区（LBA 0）。如果该扇区损坏，整个磁盘的分区表将丢失。

  • 适用场景：老旧电脑、BIOS 模式引导。

2. GPT (GUID Partition Table) - 全局唯一标识分区表

  • 历史背景：UEFI 标准的一部分，用于取代老旧的 MBR。

  • 核心优势：

    • 容量支持：理论支持最大 18EB（1EB=1024PB=1,048,576TB）。

    • 分区数量：在 Windows 系统下默认支持多达 128 个主分区，不再需要“扩展分区”和“逻辑分区”的概念。

    • 安全性：在磁盘头部和尾部各存一份分区表。同时支持 CRC32 校验，能自动检测分区表损坏并尝试修复。

    • 保护性 MBR：在磁盘开头保留一个 MBR 记录，防止不支持 GPT 的旧工具意外抹除数据。

  • 适用场景：现代电脑（Win10/11）、大容量硬盘、UEFI 引导模式。

二、 基础物理分区类型 (Basic Partition Types)

主要针对 MBR 方案下的结构划分，GPT 方案下几乎全为主分区。

1. Primary Partition (主分区)

  • 定义：磁盘上可以直接被操作系统识别和使用的独立区域。

  • 特性：

    • 可以直接安装操作系统（Win/Linux）。

    • 可以被设置为“活动分区”（Active），用于 MBR 模式下的启动。

    • MBR 磁盘最多只能有 4 个。

2. Extended Partition (扩展分区)

  • 定义：为解决 MBR 只能有 4 个分区的限制而设计的“虚拟”容器。

  • 特性：

    • 不可直接存储数据：它本身不建立文件系统，必须在其中创建“逻辑分区”才能使用。

    • 占用名额：在 MBR 中，一个扩展分区会占用 4 个主分区名额中的一个。

    • 唯一性：一个磁盘通常只建议创建一个扩展分区。

3. Logical Partition (逻辑分区)

  • 定义：在扩展分区内部划分出来的分区。

  • 特性：

    • 没有数量限制（理论受驱动器盘符 A-Z 限制）。

    • 主要用于存储文件、软件等，不能直接作为 MBR 模式下的启动分区（但可以存放部分系统的启动引导文件）。

三、 系统与功能性分区 (System & Functional Partitions)

这些分区通常由操作系统自动创建，用于特定的系统功能。

1. ESP / EFI (EFI System Partition) - EFI 系统分区

  • 格式：通常为 FAT32。

  • 作用：存放操作系统的引导程序（Bootloader）、硬件驱动、系统诊断工具等。

  • 必要性：在使用 UEFI + GPT 模式启动时，必须有 ESP 分区才能引导系统。

2. MSR (Microsoft Reserved Partition) - 微软保留分区

  • 作用：Windows 为了防止 GPT 分区表在后续操作（如将基本磁盘转换为动态磁盘）时出现空间不足，预留的一块区域。

  • 特性：

    • 一般不包含文件系统，也不显示在“我的电脑”中。

    • 大小通常为 16MB 或 128MB。

3. Recovery Partition (恢复分区 / WinRE)

  • 作用：存放 Windows 恢复环境（WinRE）。

  • 特性：

    • 当系统无法正常启动时，可以通过此分区进入修复界面（如重置此电脑、命令提示符修复）。

    • OEM 厂商（如戴尔、联想）通常还会额外设置一个巨大的 Recovery 分区，用于存放出厂镜像（一键还原）。

4. Swap Partition (交换分区)

  • 定义：Linux 系统中的一种特殊分区，类似于 Windows 的“虚拟内存”（Pagefile.sys）。

  • 作用：

    • 当物理内存（RAM）不足时，系统会将不常用的数据转移到 Swap 分区中，释放 RAM 空间。

    • 休眠功能：在 Linux 中，休眠时 RAM 中的数据通常会被写入 Swap 分区。

  • 位置：可以是一个独立分区，也可以是一个文件（Swap File）。

四、 总结与对比表

特性 MBR (旧型) GPT (现代)
最大磁盘容量 2 TB 9.4 ZB / 18 EB
分区数量上限 4 主分区 或 3主+1扩展 128 (Windows 限制)
引导模式 BIOS (Legacy) UEFI
数据安全性 无副本，易损坏 双备份 + CRC 校验
主要分区类型 主、扩展、逻辑 主分区 (几乎全是)
